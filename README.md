🎬 Movie-Rental-Analysis-Dashboard (Power BI)
📌 Project Overview

Developed an interactive movie rental analytics dashboard using Power BI to transform transactional data into meaningful insights. The dashboard supports data-driven decision-making across customers, films, and store performance.

🎯 Objectives
Analyze customer behavior and segmentation
Identify high-demand films and categories
Track sales trends over time
Evaluate store and staff performance
Understand rental patterns and seasonality
🛠️ Tech Stack
Power BI | DAX | Data Modeling
📊 Core KPIs
Total Revenue
Total Rentals
Customer Count
Average Rental Duration
Revenue by Category
Top Performing Films
Store & Staff Performance
💡 Key Insights
High-value customers contribute the majority of revenue
Premium-priced films maintain consistent demand
Rentals show noticeable seasonal trends
Staff performance impacts customer engagement and sales
Certain film categories drive higher rental frequency
🚀 Impact
Transformed raw rental data into actionable business insights
Built an interactive, user-friendly dashboard
Enabled better understanding of customer and sales behavior
Improved visibility into key performance drivers
